Obsługa wyjątków

Przykład 10.1: try_except







Objaśnienie:


    

  • W razie wystąpienia wyjątku w bloku instrukcji po słowie try, resztatego bloku jest pomijana. Python próbuje ustalić jaki rodzaj wyjątku wystąpił i przechodzi do odpowiedniej dla niego sekcji obsługi – po słowie except. W przypadku, gdy rodzaj błędu nie zostanie określony, wykonywany jest ostatni blok except – który nie jest oznaczony nazwą wyjątku.
    • 

  • Dla każdego try musi być zdefiniowane przynajmniej jedna sekcja wyjątków  except.
    • 

  • Gdy nie obsłużymy błędu za pomocą except, wtedy Python domyślnie zatrzymuje program i wyświetla komunikat o błędzie – tak jak to wcześniej pokazano.
    • 

  • Blok else w przypadku try działa podobnie jak przy if oraz while –   wykonywany jest wówczas, gdy nie wystąpił żaden wyjątek.
    •
